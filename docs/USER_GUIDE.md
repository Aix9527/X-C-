# X C盘巡检官：使用说明

## 开始

首次启动不会自动扫描，也不会自动申请管理员权限。首页先显示 C 盘总量、已用、可用容量。

1. 可先调整“大文件阈值”，默认 500 MB。
2. 点击“开始扫描”。
3. 扫描期间可查看当前目录、文件数量、累计逻辑容量和耗时，也可以取消。
4. 取消后仍会形成“不完整”报告，但批量清理会被禁用。
5. “载入上次报告”用于恢复历史扫描快照。载入后旧勾选会被清空，但可以重新选择；真正删除前程序会按当前规则和当前文件状态逐项实时复核。

## 阅读扫描结果

- **主要占用**：按 C 盘一级目录和根目录文件汇总。
- **重点目录**：显示软件/系统、用途、风险、完全删除后果、建议和禁止原因。
- **大文件**：只表示“大”，不表示“垃圾”。
- **清理候选**：只有通过规则库允许列表的项目才出现可选项。

你可以按风险、建议、软件和最小容量筛选。

- **全选建议项**：只选择当前筛选范围内的低/中风险建议项。
- **一键全选**：选择当前筛选结果中所有仍然可选择、且具有清理允许规则的项目。
- **软件分类 + 分类全选**：只选择当前筛选范围内指定软件分类的可选择项目。
- **取消全选**：清空当前清理选择。

所有批量选择都不会绕过 `Selectable`、清理允许规则或安全路径限制。

## 执行安全清理

1. 在扫描结果或安全清理页勾选项目。历史报告载入后也可以重新选择。
2. 点击“一键删除已选项”。
3. 程序重新验证扫描完整性、当前规则、路径、允许列表并去除父子重复目标；历史报告走专用实时复核通道，不直接信任旧报告中的清理授权字段。
4. 最终确认窗口列出真实执行清单。
5. 如果包含回收站，必须单独勾选“我理解回收站清空后无法恢复”。回收站只针对候选所在驱动器执行；C 盘规则不会清空其他驱动器的回收站。
6. 确认后按清单顺序执行，并自动切换到“安全清理”页显示进度。

### 删除进度与大文件

清理页会显示：

- 当前第几项 / 总项目数；
- 已处理的预计逻辑容量 / 总预计逻辑容量；
- 总体百分比；
- 当前正在处理的文件路径。

单个文件实际删除由后台线程执行，因此即使 10 GB 以上大文件受到磁盘、杀毒软件或文件系统过滤驱动影响而耗时较长，WPF 主界面也应保持可响应。

Windows 的 `File.Delete` 不提供可信的“单个文件逐字节删除进度”，因此程序不会伪造单个大文件内部的 37%、58% 等百分比；进度条表示整个已确认清单的总体进度，并明确显示当前正在删除哪个文件。

执行中可以点击“停止后续项目”。这会在当前项目完成后停止，不会强制中断正在删除的单个文件。

### 管理员权限重试

程序不会在普通启动时自动申请管理员权限。

当一个已经通过安全复核的清理候选仅因为权限不足而失败时，程序会询问是否获取管理员权限重试：

1. 只有用户明确选择“是”才会弹出 Windows UAC；
2. 只重试本轮因权限不足失败的候选；
3. 提权进程会重新加载当前规则，并再次执行路径、规则、重解析点、文件大小、修改时间和保留时间等复核；
4. 管理员权限只改变进程访问权限，不扩大允许删除的路径范围；
5. 用户取消 UAC 时，原权限失败结果会保留，不会继续删除。

## 系统优化建议

系统优化页只提供官方入口：

- 页面文件：说明如何调整，不删除 `pagefile.sys`。
- 组件存储：调用 DISM `AnalyzeComponentStore` / `StartComponentCleanup`。
- 软件卸载：打开 `ms-settings:appsfeatures`。
- WSL/Docker：提供官方清理与压缩指导。

需要管理员权限的官方系统操作会由 Windows UAC 单独确认。

## 报告

“关于与报告”页可导出 JSON 或 HTML。报告包含扫描时间、程序版本、规则版本、管理员状态、容量、风险、后果和建议，不包含文件内容或密钥。

历史 JSON 报告读取后会由程序内部标记为持久化来源，这个状态不来自 JSON 字段。普通实时预览服务仍拒绝把持久化报告本身当作删除授权；只有用户重新选择后，专用历史报告复核服务才会按当前机器和当前规则重新生成可执行候选。
